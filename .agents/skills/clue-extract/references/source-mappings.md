## Source mappings

Per-source mappings live in this skill's `mappings/` folder: [openspec.md](../mappings/openspec.md) for OpenSpec corpora, [madr.md](../mappings/madr.md) for MADR and Nygard-style decision records. The target contract governs every extraction; a mapping only describes one source format. A new source format adds a mapping file, never another skill. If no mapping exists, writing one is the extraction PR's first task.
