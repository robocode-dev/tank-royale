# Release changelog precondition

The 1.2.0 release proceeded while its top changelog heading still said `Unreleased`. Require a dated top entry before artifact publication or GitHub release creation, and correct the 1.2.0 entry to its release date.

This change is plan-less. It enforces the existing changelog format rather than changing a product capability.
