## Should downloaded bots appear in the New Battle bot list automatically?

If the download folder is registered as an ordinary bot directory, its bots show up beside the author's own in every battle setup, which is convenient for practice but can crowd the list with hundreds of entries. The recommendation is to register the folder automatically but show it as a labelled, collapsible group that starts collapsed, so the author's own bots stay first. The alternative is that the folder stays unregistered until the author turns it on.

## Is a managed folder wanted, or only a single-bot Download button?

The managed folder supports selecting many or all bots and refreshing them. A single button on a bot's details page needs no new setting but gives no way to refresh or remove a set. The recommendation is the managed folder, with the single-bot case being a selection of one.
