## Should an AI agent work with its own GitHub account or with the participant's?

Resolved by the maintainer on 2026-11-02: the participant's own account first; an account of the agent's own may be added later if someone wants it.

An agent that runs the command line as the participant's operating system user can read the participant's saved sign-in, so giving it an account of its own would have protected nothing by itself, and would have required Rumble to accept accounts operated by software: who owns a bot, whose name is in the rankings and who answers for a violation. The participant's own account needs no new rule, and the registration and the one-open-pull-request-per-bot rule already assume it.
