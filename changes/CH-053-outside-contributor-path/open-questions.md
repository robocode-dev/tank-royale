# CH-053 — Open questions

## Which non-member account runs the experiment?

The exit criterion requires an account that is not an organization member and has no push access to any Rumble repository. Which account should be used, who controls it, and is it registered (or should it be registered) in `rumble-data` as a client? The experiment needs authorized test data so it does not pollute published rankings. Without an answer the experiment cannot start, and a maintainer or prepared account cannot substitute.
