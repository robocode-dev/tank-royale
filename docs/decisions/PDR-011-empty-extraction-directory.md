# PDR-011 — Empty extracted specifications create no capability

## Context

The `browser-sample-bots` OpenSpec directory contained no requirements to preserve.

## Decision

The empty directory produces no capability and its would-be BSB prefix remains unregistered.

## Consequences

The corpus does not contain a hollow capability whose criteria and evidence would have no meaning.
