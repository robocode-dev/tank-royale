# PDR-007 — Extracted criteria start as draft

## Context

The brownfield corpus contains many extracted criteria whose tests do not yet carry Cliewen purpose tags.

## Decision

Extracted criteria begin with `status: draft` and become active per capability when their tests carry the required purpose tags.

## Consequences

Test-tagging can proceed capability by capability without weakening the active-criteria evidence wall or requiring a repository-wide big bang.
