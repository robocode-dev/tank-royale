# PDR-005 — GUI TwinDuel ships before Rumble documentation

## Context

The GUI is the primary product entry point, so the TwinDuel selection must be complete in the 1.1.0 experience before the remaining Rumble guides are published.

## Decision

M-010 precedes M-009 and ships GUI TwinDuel selection in Tank Royale 1.1.0.

## Consequences

Users encounter the complete common game-type experience before the Rumble documentation describes the settled client and GUI interfaces.
