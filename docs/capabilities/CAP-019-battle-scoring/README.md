# CAP-019 — Battle scoring

Tank Royale calculates each bot's score from its battle actions and survival, then combines team members' scores for team results. Its team-battle survival awards follow the classic Robocode rules so bots receive credit for defeating opponents without receiving survival points for teammate deaths.
